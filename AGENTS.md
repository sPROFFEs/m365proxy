# Repository Guidelines and Context

## Scope and Core Mandates
- Adhere strictly to existing project conventions when reading or modifying code.
- Never assume a library/framework is available; verify established usage in project configuration first.
- Maintain style, formatting, naming, structure, framework choices, and architecture patterns of existing code.
- Add code comments sparingly, focusing on *why* something is done rather than *what* is done.
- Never revert changes unless requested or in the event of an error.

## Workflows and Verification
1. **Understand:** Inspect codebase context, file structures, and conventions using search and read tools.
2. **Plan:** Build a coherent and grounded plan for the task.
3. **Implement:** Execute changes adhering to project conventions.
4. **Verify:** Run test suites and verify code quality.
